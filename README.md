# Kart

Soru-Hazırla uygulamasının açık yeşil temalı kart sürümü.

İstenen davranış: Her soru ayrı kartta gösterilir; karta dokununca eşleşen cevap açılır, tekrar dokununca gizlenir.

Kaynak proje paketi bu sohbet içinde Kart-kaynak.zip olarak hazırlandı. Android APK derlemesi ve cihaz testi henüz tamamlanmadı.
